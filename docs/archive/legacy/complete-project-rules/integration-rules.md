# 🔐 Integration Rules & Protocol

## 📖 Project Understanding Before Any Change
Before making any modification (bug fix, feature, or integration):

1. 📚 Understand full project architecture:
   - Folder structure
   - Data & module flow
   - Database schema

2. 🔁 Review latest CHANGELOG.md

3. 📂 Review critical directories:
   - /modules/
   - /controllers/
   - /interfaces/

4. 🧠 Confirm:
   - Input > Processing > Output logic
   - Public vs internal module access

5. 📝 Log your plan in CHANGELOG.md before implementing

6. ⚠️ Do NOT guess logic. Read before writing.
